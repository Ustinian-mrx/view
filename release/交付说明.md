## 功能概述

本项目为 Flutter + Android 原生的离线实时视觉辅助 App。程序使用手机后置相机采集 YUV420 图像流，通过 Android 方法通道进入 NCNN 原生推理层，完成目标检测、风险提示、语音播报、震动提醒、低光自动补光、检测框叠加和环境感知地图展示。

当前 App 已接入端侧 NCNN 推理，包含模型文件、NCNN shared runtime、JNI 桥接代码和 Flutter 展示层。算法侧支持 YOLOv8 风格输出解码、交通灯颜色判断、盲道/台阶轻量场景线索补充、低光/低对比增强和 fallback 检测。

## 运行方式

1. 安装 Flutter SDK 和 Android SDK。
2. 在 `android/local.properties` 中确认 `sdk.dir` 和 `flutter.sdk` 指向本机路径。
3. 执行依赖获取：

   ```bash
   flutter pub get
   ```

4. 构建 APK：

   ```bash
   cd android
   .\gradlew.bat :app:assembleDebug --offline --no-daemon
   ```

5. 安装 APK：

   ```bash
   adb install -r release/vision_guard-debug.apk
   ```

首次启动时需要允许相机权限。
